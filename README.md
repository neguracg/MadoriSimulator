# 間取りシミュレーター (Madori Simulator)

> 機能の正本はこの README、時系列は docs/WORKLOG.md、不具合は docs/BUGLOG.md、設計判断は docs/KANSA_20260928.md §4。

## 何のツールか

方眼紙感覚で住宅の間取りをざっくり組み替えながら、部屋の配置・広さ・全体面積を試行錯誤するためのブラウザツールです。精密な CAD ではなく「変更の容易さ」を重視した概算ツールで、サーバーは使わず、データはブラウザの中だけに保存されます。

## 使い方

### 開く

- 公開版: https://neguracg.github.io/MadoriSimulator/ をブラウザで開くだけです（インストール不要）。
- 自分の PC で動かす: `起動.bat` をダブルクリックします（初回は `npm install` が自動で走ります。Node.js 18 以上が必要）。ブラウザが http://localhost:5173 で開きます。終了は `起動.bat` のウィンドウを閉じます。

### データの保存先（バックアップ推奨）

- 間取りは、変更のたびにこのブラウザの localStorage へ自動で保存されます（サーバーへは送られません）。
- 保存先は **端末・ブラウザ・URL（ポート番号まで）ごとに別** です。公開版と `http://localhost:5173` は互いに見えず、別のブラウザ・別の PC・別のポートでも同じです。
- サイトデータの消去などで消えたデータは戻りません。大事な間取りは「💾 ファイル ▾」→「全部まとめてバックアップ (JSON)」で書き出して保管してください。

### ポートに注意

開発サーバーは 5173 を使い、塞がっていても別のポートへは逃げず、エラーで止まります（ポートが変わると保存先が変わり、間取りが空に見えるため）。`起動.bat` が「Could not start the server」と表示して止まったら、既に起動中でないか確認し、起動中なら http://localhost:5173 を開いてください。

## 機能一覧

画面は、上にヘッダー（「1階」「2階」の切替・ズーム・「⚙ 設定」「🔗 共有」「🖨 印刷」「💾 ファイル ▾」）と間取りタブ、左にツールバー、中央にキャンバス、右にプロパティと面積サマリーが並びます。

### 部屋

- **方眼**: 1マス = 455mm、2マスごとに太線（既定なら 910mm）、64×64 マス。部屋は「占有マスの集合」で、面積（㎡ / 畳 / 坪。1畳 = 1.62㎡）を自動計算します。「⚙ 設定」で 1マスを 100〜1000mm、壁厚（既定 120mm）を 50〜400mm に変えられます。
- **作成**: 編集モードで空きマスをドラッグ（またはクリック）して範囲を選び、「＋ 部屋を作成」→ 部屋名（改行可。空なら種別名）と種別を決めて「作成」（部屋名の欄で Ctrl+Enter でも作成）。
- **伸縮**: 部屋を選ぶと辺の中央に四角のハンドル、長方形の部屋は四隅に丸のハンドルが出ます。つかんでドラッグします。右パネルの「＋ マス追加」「－ マス削除」を押してから、マスをドラッグ／クリックして足す・削る方法もあります。
- **編集モードでは部屋は重ならない**: 作成・伸縮・マス追加で別の部屋のマスに触れると、そのマスは操作した部屋のものになります。マスが分断された部屋は、自動で別々の部屋に分かれます（「名前 2」など）。
- **種別と色**: 種別は初期状態で 居室・LDK・水回り・収納・玄関・廊下・階段・その他。「⚙ 設定」で種別の名前・色の変更と追加ができ、部屋ごとの色の上書きは右パネルの「色（この部屋のみ）」です（「種別色に戻す」で解除）。
- **重なり順**: 部屋を右クリック →「前面へ」「1つ前へ」「1つ後ろへ」「背面へ」。
- **削除**: 右パネルの「この部屋を削除」／右クリック →「削除」／ Delete。
- **表示**: 部屋の中に名前と面積（㎡ / 畳）を出し、全部屋の外周を外壁として太く描きます。外周と選択中の部屋には各辺の長さ（m）が出ます。ズームを下げ過ぎる（約 55% 未満）と文字は隠れます。表示していない側の階の外壁は、オレンジの点線で薄く出ます（1階と2階を揃える目安）。
- **面積サマリー**（右パネルの下）: 1階・2階・延床の ㎡ / 畳 / 坪、表示中の階の「外周内マス数」（部屋全体に外接する四角形のマス数）と「空きマス」（その四角形の中で部屋に使われていないマス）。壁厚は表示用で面積には影響せず、面積は「マス数 × 1マスの面積」です。

### 編集モードと移動モード

ツールバーの「編集」「移動」で切り替えます。

- **移動モード**: 部屋をドラッグして、マス単位で動かします。重なりは許され、編集モードへ戻る時に確定します（重なったマスは上のレイヤーの部屋のものになり、下の部屋は削られ、分断されれば分かれます）。移動先がグリッドの端を越える場合は、形を保ったまま端で止まります。階の切替・間取りタブの切替／追加／複製・ファイルの読み込みの時にも確定します。
- **部屋と一緒に動くもの**: 外壁側のドア／窓（隣の部屋と共有する壁のものは動きません）と、中心が部屋の中にある家具。確定の結果、壁でなくなったドア／窓は取り除かれます。
- 移動モード中は、ツールバーの「部屋を作成」「家具を作成」「ドア／窓を追加」が無効になり、伸縮ハンドルと家具の移動も使えません。

### ドア・窓

- **追加**: ツールバーの「🚪 ドア／窓を追加」（部屋の右クリック →「🚪 ドア／窓を追加」でも同じ）。ダイアログで「ドア」か「窓」を選び、幅をボタン（ドア 600・700・750・800・900・1200mm／窓 600・900・1200・1650・1690・1800mm）か「カスタム幅」（100〜4000mm）で決めると配置待ちになります。カーソルに最も近い壁の位置に薄く表示され、クリックで確定、Esc か「中止」で取りやめです。
- **操作**: ドラッグで別の壁の位置へ動かせます（最寄りの壁に吸着）。右クリックで「幅を変更…」「ドア⇄窓を切替」「削除」。選んで Delete でも削除できます。
- **部屋との連動**: 部屋の形を変える（辺・角のドラッグ、マスの追加・削除）と、壁が動いた分だけドア／窓も追随します。部屋を削除すると、その部屋の壁にあったドア／窓も消えます（隣の部屋と共有する壁のものは、隣の部屋が残る限り残ります）。

### 家具

- 「🪑 家具を作成」を押してから、キャンバスをドラッグして四角を描きます（幅・奥行とも 80mm 以上）。ミリ単位の自由配置で、方眼には吸着しません。
- 作成後は、ドラッグで移動、四隅の丸でサイズ変更。右パネルで名前・幅・奥行（mm。20 以上）・色を変えられ、「この家具を削除」（Delete でも）で消せます。

### コピー・切り取り・貼り付け

部屋または家具を選んで Ctrl+C / Ctrl+X / Ctrl+V。クリップボードはアプリの中にあり、階や間取りタブをまたいで貼り付けられます（ドア／窓はコピーできません）。同じ階の同じ間取りへ貼ると 1マス分ずれた位置に、別の階・別の間取りへは同じ位置に入ります。部屋を貼ると移動モードになり、貼った部屋が選ばれた状態になります（他の部屋に重なっていても、編集モードへ戻る時に確定します）。貼り付け先に無い種別は、部屋と一緒に追加されます。

### 元に戻す・やり直す

「↶ Undo」「↷ Redo」（Ctrl+Z / Ctrl+Y）。200 手までです。同じ項目への連続した入力（文字入力・色選択・数値入力。間隔が 1.5 秒以内）は 1 手にまとまります。

### 間取りタブ・複製

- 複数の間取りをタブで持てます（すべての間取りが 1 つにまとめて自動保存されます）。初回は空の「間取り 1」が 1 枚あります。「＋」で空の間取りを追加、タブのダブルクリックで名前変更、「×」で削除です（確認あり。間取りが 2 つ以上ある時だけ表示されます）。
- 選んでいるタブの「⧉」で、その間取りを複製します。「<名前> のコピー」という新しいタブが開きます（中身は元から独立した複製です）。案を少し変えて比べる使い方を想定しています。

### 共有（リンク・QR）

「🔗 共有」で、表示中の間取りを埋め込んだリンクと QR コードを作ります。サーバーは使わず、間取りの内容そのものを圧縮して URL の `#p=` 以降に入れる方式です。相手が開くと、その間取りが新しいタブとして追加されます（相手の既存の間取りは置き換わりません）。ローカル起動中（localhost など）に作ったリンクは、他の端末で開けるよう公開版の URL（`https://neguracg.github.io/MadoriSimulator/`）を基にします。URL が 2000 文字を超えると、古い端末・アプリでは開けない場合があるという注意が出ます。

### 印刷

「🖨 印刷」（ブラウザの Ctrl+P でも同じ）。画面の操作部品は出さず、部屋がある階ごとに 1 ページ（A4 縦を想定）で、見出し「<間取り名> ― <n>階」・1マスの寸法と壁厚・読み取り専用の全体図（ドア／窓・家具を含む）・部屋の一覧（部屋・種別・㎡・畳）・その階の合計と延床面積を出します。部屋の色も印刷されます。部屋が 1 つも無い間取りは「部屋がまだありません。」の 1 ページになります。移動モードの途中でも、重なりを確定した状態で印刷します（画面の間取りは変わりません）。

### ファイル（書き出し・バックアップ・読み込み）

「💾 ファイル ▾」メニューに 3 つの項目があります。

- 「この間取りを書き出し (JSON)」: 表示中の間取り 1 つを `<間取り名>.json` で保存します。
- 「全部まとめてバックアップ (JSON)」: すべての間取りを `madori-backup-YYYY-MM-DD.json` で保存します。
- 「ファイルから読み込み…（新しいタブに追加）」: 上の 2 種類のどちらのファイルも読めます。読み込んだ間取りは新しいタブとして追加され（バックアップなら全部。1 つの間取りのファイルは、拡張子を除いたファイル名が間取り名になります）、今の間取りは置き換わりません。「N件の間取りを追加しました」と通知が出ます。読めないファイルは「JSONの読み込みに失敗しました。」と出て、何も変わりません。

古い形式や一部が壊れたデータ（ドア／窓や 2 階の情報が無い、範囲外のマスがある、など）は、読み込み時に補正されます。起動時の保存データと共有リンクも同じです。

### 表示（ズーム・スマホ）

- ズーム: ヘッダーの「－」「＋」（20% 刻み、40〜250%）。「全体」は、表示中の階の内容（部屋・ドア／窓・家具）がすべて見える大きさと位置に合わせます（何も無ければ 100%・左上）。
- 画面の幅が 820px 以下（スマホ）では 1 列の配置になり（キャンバス → ツールバー → 右パネルの順）、ヘッダーは折り返します。タッチでは、1 本指が図面の操作（範囲選択・ドラッグ）、**2 本指がキャンバスのスクロール**です。

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl+C / Ctrl+X / Ctrl+V | 選んだ部屋・家具のコピー / 切り取り / 貼り付け |
| Delete / Backspace | 選んだ部屋・家具・ドア／窓を削除 |
| Esc | ダイアログ・メニューを閉じる。何も開いていなければ、マスの追加／削除・範囲選択・ドア／窓の配置待ち・家具の作成待ちを解除 |
| Ctrl+Enter | 部屋の作成ダイアログで「作成」（部屋名の欄から） |
| Ctrl+P（ブラウザ標準） | 印刷（「🖨 印刷」と同じ） |

Ctrl は Mac では ⌘ でも効きます。ダイアログ・メニューを開いている間は、Esc（閉じる）とダイアログ内の Ctrl+Enter 以外のショートカットは効かず、入力欄・セレクトにフォーカスがある間も効きません。

## 開発

React 18 + TypeScript + Vite 5。共有リンクの圧縮に lz-string、QR に qrcode を使います。Node.js 18 以上が必要です。

```bash
npm install
npm run dev                  # 開発サーバー（http://localhost:5173。ポートが塞がっていると止まる。ブラウザは自動では開かない）
npm run build                # 型検査（tsc）+ 本番ビルド → dist/
npx vitest run               # 単体テスト（npm test でも同じ。件数はここで確認する）
python scripts/ui_check.py   # 画面E2E（下記）
npm run deploy               # build して dist/ を gh-pages ブランチへ公開する（公開版が更新される）
```

- **画面E2E**（`scripts/ui_check.py`）: ヘッドレスの Chrome（Playwright）で、開発サーバー（dev）と本番ビルド（prod）の両方を自分で起動して操作し、終了時に必ず止めます。Python・Playwright・Chrome が必要です（`pip install playwright && python -m playwright install chrome`）。prod は先に `npm run build` が必要で（`dist/` が `src/` より古いと止まります）、ポート 4178 / 4179 が空いていること。オプション: `--target dev|prod|both`（既定は both）、`--only <名前の一部>`、`--list`（シナリオ一覧）。終了コードは 0=全て成功 / 1=失敗あり / 2=起動・環境エラー。スクリーンショットは `docs/shots/`（git 管理外）へ出ます。
- **ブラウザの自動オープン**: `vite.config.ts` は開発サーバー・`vite preview` とも自動ではブラウザを開きません（`server.open`・`preview.open` を `false` に固定）。開くのは `起動.bat`（`npm run dev -- --open`）だけです。試験・サブエージェント・プレビューが何度サーバーを起動しても、利用者の Chrome にタブが増えないようにするためで、`ui_check.py` は念のため env `BROWSER=none` も付けて起動します。`src/lint/noAutoOpen.test.ts` が設定と `起動.bat` の両方を固定します。
- **公開先の住所**: `src/constants.ts` の `PUBLIC_APP_URL` の 1 行が正本です。`vite.config.ts` の本番ビルドの基底パス（`/MadoriSimulator/`）・共有リンクの基底・`ui_check.py` の prod 起動は、すべてこの行から導きます。
- **コードの読み方**: 各ソースの 1 行目のコメント `@owns` が、そのファイルの担当する概念です。間取りの編集操作は `src/state/docOps.ts` を通り、外から入る間取り文書（保存データ・読み込んだファイル・共有リンク）は `src/state/migrate.ts` の `acceptDoc` を通ります（それ以外が `normalizeDoc` を直接呼ぶと `src/lint/docEntrance.test.ts` が落ちます）。
- **docs/**: `WORKLOG.md`（作業ログ）・`BUGLOG.md`（バグ台帳）・`KANSA_20260928.md`（全体監査の所見と設計判断）。`SHIJI_20261007_kansa.md` は完了済みの修正指示書で、記録として残しています。

## 既知の制約

- **データはこのブラウザの中だけ**: localStorage に保存するため、別の端末・ブラウザ・URL（ポート番号）とは共有されず、サイトデータの消去などで消えると戻りません。定期的に「全部まとめてバックアップ (JSON)」を取ってください。容量の上限などで保存できない時は、ヘッダーの下に赤い帯「保存に失敗しました。ファイルへ書き出して退避してください」が出ます（その場合も「この間取りを書き出し (JSON)」は使えます）。
- **退避キー**: 起動のたびに、読み込む前の保存内容（＝今回の作業を始める前の状態）を `madori-simulator-project-v1.backup-prev` へそのままコピーします（1 世代分）。保存内容が読めなかった場合（壊れた JSON・文書の無い間取りを含むなど）は、元の内容を `madori-simulator-project-v1.corrupt-<日時>`（新しい 3 件まで）へ退避してから起動します。どちらも画面からは見えず、戻す操作もありません。ブラウザの開発者ツール（Application → Local Storage）で中身を取り出して使います。
- **2 つのタブで同時に編集すると後勝ち**: 同じ間取りを 2 つのブラウザタブで編集すると、後から保存したタブの内容が残り、もう一方の変更は失われます。別のタブで増えた間取りはこのタブへ自動で追加されます（「別のタブの間取りをN件追加しました」）が、別のタブでの削除は反映されません。編集は 1 つのタブで行ってください。
- **スマホ**: スマホ幅の表示と 2 本指スクロールは、Chrome（幅 390px のモバイル端末エミュレーション・タッチ入力）での確認のみです。iOS Safari・実機・実際のプリンタでは確認していません。
- **公開版の内容**: 公開版（GitHub Pages）は、最後に `npm run deploy` した時点の内容で、master の最新とは限りません。`起動.bat` で動かす版は、手元のソースの内容です。
- **扱える範囲**: 1階・2階のみ、64×64 マスの範囲、壁はマスの辺（斜め・曲線は不可）、家具は四角のみで回転できません。ドア／窓は壁の位置を示す印で、開き方向などは持ちません。
- **履歴**: Undo / Redo は表示中の間取りの分だけで、間取りタブの切替・追加・複製・読み込みや、ページの再読み込みで消えます。間取りタブの削除は Undo できません。
